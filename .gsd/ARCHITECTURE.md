## Data Flow

1. **User Authentication & Onboarding:**
   - User signs up / logs in via `apps/web` → Request sent to `apps/api/app/api/routes/auth.py` → JWT token returned and stored in session/cookie.

2. **Project & Team Space Creation:**
   - User browses community templates or creates a custom project → Next.js calls `apps/api/app/api/routes/projects.py` / `team_space.py` → Data persisted to database via SQLAlchemy ORM.

3. **Telemetry & Proof of Work Generation:**
   - Developer pushes code to GitHub → `sensor.py` polls/ingests commit & PR evidence → Computes skill scores and updates proof models (`apps/api/app/models/proof.py`) → Front-end displays evidence-backed portfolio cards on `/proof`.
