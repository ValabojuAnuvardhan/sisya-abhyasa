# Śiṣya Abhyāsa — Mentor Guide

**Target Version:** v1.0.0  
**Target Audience:** Academic Mentors, Industry Advisors, Project Owners  
**Document Path:** `docs/user-guide/mentor_guide.md`  

---

## 1. Mentor Responsibilities
- Guide student teams through 6-week project roadmaps.
- Review and approve join requests submitted by contributor candidates.
- Assign tasks based on skill match explanations.
- Review GitHub Pull Requests for code quality before merging into `main`.

---

## 2. Facilitating Learning via `@mentor`
- Encourage students to tag `#task-id` in Team Space chat.
- Advise students to use `@mentor` for contextual debugging and architectural guidance.
- Reinforce that AI guidance complements—rather than replaces—team code reviews.

---

## 3. GitHub PR Reviews & Evidence Interpretation
- Verify that student PRs contain working code meeting the task's **Completion Criteria**.
- When merging a PR on GitHub, Śiṣya's Evidence Engine evaluates the diff and issues **Demonstrated Skill Evidence**.
- Remind students that evidence is only issued upon PR merge, not task assignment or chat participation alone.
